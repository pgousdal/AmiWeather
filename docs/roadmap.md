# Roadmap

- **M0 — Foundation:** external AmiAPI integration, native GUI shell,
  deterministic Open-Meteo parsing, and a real-request proof.
- **M1 — Current weather:** connect current conditions to a usable native
  presentation and refine error/progress handling.
- **M2 — Locations:** add geocoding and practical location selection.
- **M3 — Forecast:** present forecast data with a polished, restrained classic
  Amiga interface.
- **M4 — Usability:** preferences, persistence, and platform hardening.

Each milestone should remain independently testable and avoid prematurely
introducing background or elaborate UI infrastructure.
